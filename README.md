**KlaKlouk Brainrot** is a modern digital adaptation of the traditional Cambodian **Kla Klouk** dice game, developed using **C# and .NET Windows Forms**.  
Inspired by the internet’s “Brainrot” trend and Gen Z meme culture, the project combines classic gambling gameplay with a chaotic and entertaining visual style.

# Features

- Traditional Kla Klouk gameplay recreated digitally.
- Unique **Brainrot / Meme style interface**.
- Betting system with virtual money.
- Meme sound effects.
- Multiple betting choices.
- Real-time win/lose calculation.
- Khmer language support.
- Custom-designed UI components and assets.
